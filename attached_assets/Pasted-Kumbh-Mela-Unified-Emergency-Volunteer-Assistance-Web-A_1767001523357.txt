Kumbh Mela Unified Emergency & Volunteer Assistance Web App (QR-Based)

🎯 OBJECTIVE

Create a single unified website (same domain, same QR code) used by pilgrims (users) and volunteers during Kumbh Mela to report emergencies and view live locations in real time on a single map dashboard.

🧭 START PAGE (MAIN PAGE /)

This page opens when the universal QR code is scanned.

Show 4 BIG ACTION BUTTONS

🟥 Medical Emergency

🟣 I Lost Myself(ATTACH P) 

🟡 Lost Someone

🟢 Volunteer Help

Below these buttons:

🔐 Volunteer Login (Username + Password)

🌐 Language Selector:
English | Hindi | Marathi | Tamil | Telugu

🧑‍🦯 USER FLOW (NO LOGIN REQUIRED)
On Clicking Any Option:

Ask for location permission (mandatory).

Ask for basic details:

Name (optional)

Mobile number (optional)

Start live location tracking (every 10–15 seconds).

Tracking automatically expires after 1 hour.

User must scan QR again to restart tracking.

🟡 LOST SOMEONE (SPECIAL CASE)

Additional fields:

Upload photo of missing person (camera or gallery).

Optional:

Age

Gender

Last seen note

Photo must:

Be visible to volunteers on marker click

Not be downloadable

Auto-delete after 1 hour
